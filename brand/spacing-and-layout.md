# Spacing and layout

- **Canvas:** 960 x 540 dp (1080p TV at 2.0x).
- **Overscan safe area:** 38dp left and right, 14dp top. Content never touches the screen edge.
- **Spacing scale (dp):** 2, 4, 8, 12, 16, 24, 32, 48.
- **Grid:** 4dp baseline; horizontal rows start at 40dp so the first focused tile is fully inside the safe area.

## Home structure (top to bottom)

1. Header: mark, wordmark, tagline; clock and date on the right.
2. Greeting and one-line status.
3. Featured strip (pinned favourites).
4. App rows (Favourites, Media and Cinema, Library, Tools).
5. Bottom navigation: Home, Shows, Apps, Streaming, Quick, Settings.

The Shows tab replaces items 3 and 4 with channel chips and a poster grid.
